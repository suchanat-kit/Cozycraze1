# ร้านค้า POS (PWA + Google Sheets)

ระบบขายหน้าร้านสำหรับใช้เครื่องเดียว: ขาย ตัดสต็อก ปรับสต็อก และออกใบเสร็จ (พิมพ์ได้ทั้งกระดาษ 80/58 มม., บันทึกเป็น PDF หรือแชร์)

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.json`, `sw.js`, `icon-*.png` | ทำให้ติดตั้งเป็นแอปและเปิดแบบออฟไลน์ได้ |
| `Code.gs` | Backend ที่วางใน Google Apps Script |

## ติดตั้ง
### 1. Google Sheets
1. สร้าง Google Sheet ใหม่ แล้วเปิด Extensions → Apps Script
2. วางโค้ดจาก `Code.gs` (ถ้าต้องการรหัสลับ ให้ตั้งค่า `API_KEY`)
3. Project Settings → Time zone → (GMT+07:00) Bangkok
4. เลือกฟังก์ชัน `setup` แล้วกด Run และกดอนุญาตสิทธิ์ ระบบจะสร้างชีต Products, Receipts, SaleItems, StockLog ให้
5. Deploy → New deployment → Web app · Execute as: **Me** · Who has access: **Anyone** แล้วคัดลอก URL ไว้

> แก้ `Code.gs` แล้วต้องไปที่ Deploy → Manage deployments → ✏️ → Version: New version ทุกครั้ง

### 2. หน้าเว็บ (GitHub Pages)
1. สร้าง repo แล้วอัปโหลดไฟล์ทั้งหมด ยกเว้น `Code.gs`
2. Settings → Pages → Branch: `main` / root → Save
3. เปิด `https://<username>.github.io/<repo>/` ไปที่แท็บ **ตั้งค่า** วาง URL ของ Web App แล้วกดบันทึก
4. บนมือถือ กด "เพิ่มไปยังหน้าจอหลัก" เพื่อใช้งานเหมือนแอป

ถ้ายังไม่ใส่ URL แอปจะทำงานใน **โหมดเดโม** โดยเก็บข้อมูลไว้ในเครื่อง

## ใช้งาน
- **เพิ่ม / แก้ไข / ลบสินค้า และใส่รูป**: แท็บสต็อก → ปุ่ม "+ เพิ่มสินค้า" หรือ "แก้ไข" ข้อมูลบันทึกลงชีต `Products` ทันที รูปจะถูกย่อเหลือ 240×240 แล้วเก็บในคอลัมน์ `image` (อย่าแก้คอลัมน์นี้ในชีตด้วยมือ)
- **ขาย**: แตะสินค้าเพื่อใส่ตะกร้า → ชำระเงิน → ใส่ยอดเงินที่รับมา → ยืนยัน แล้วใบเสร็จจะขึ้นทันที
- **ปรับสต็อก**: ใช้แท็บสต็อก กด −/+ หรือ "ปรับหลายชิ้น" ทุกครั้งจะถูกบันทึกใน `StockLog`
- **ใบเสร็จย้อนหลัง**: ดูได้ที่แท็บใบเสร็จ (เก็บในเครื่อง 200 ใบ) ข้อมูลทั้งหมดอยู่ในชีต `Receipts` / `SaleItems`

## เครื่องพิมพ์ใบเสร็จ Bluetooth (พิมพ์ตรง ไม่ผ่านหน้าต่างพิมพ์)
แอปจะแปลงใบเสร็จเป็นรูปแล้วส่งคำสั่ง ESC/POS ไปที่เครื่องพิมพ์ ภาษาไทยจึงพิมพ์ออกมาถูกต้องเสมอ ไม่ต้องตั้ง code page ใดๆ

**iPhone / iPad**: Safari ไม่รองรับ Bluetooth ต้องใช้แอป **Bluefy – Web BLE Browser** (ฟรีใน App Store)
1. เปิดเว็บ `https://<username>.github.io/<repo>/` ในแอป Bluefy แล้วกดเพิ่มบุ๊กมาร์กไว้
2. เปิดเครื่องพิมพ์ทิ้งไว้ **ไม่ต้อง** จับคู่ในเมนู Bluetooth ของ iPhone
3. ไปที่แท็บ ตั้งค่า → ขนาดกระดาษ 58 มม. → เครื่องพิมพ์ Bluetooth → **เชื่อมต่อ** → เลือกเครื่องพิมพ์ → **พิมพ์ทดสอบ**
4. ทุกครั้งที่เปิดแอปใหม่ ต้องกด "เชื่อมต่อ" อีกครั้ง หลังจากนั้นทุกบิลจะพิมพ์อัตโนมัติหลังกดยืนยันการขาย

**Android**: ใช้ Chrome ได้เลย ทำขั้นตอนที่ 3 เหมือนกัน

**ถ้ามีปัญหา**
- รายชื่อเครื่องพิมพ์ไม่ขึ้น หรือขึ้นว่า "ไม่พบช่องส่งงานพิมพ์": เครื่องพิมพ์อาจรองรับแค่ Bluetooth แบบเก่า (Classic) ซึ่ง iPhone ไม่เปิดให้เว็บหรือแอปทั่วไปใช้ ให้กด **แชร์รูป** แล้วเปิดในแอปของยี่ห้อเครื่องพิมพ์แทน
- พิมพ์ออกมาเพี้ยน ขาดเป็นช่วง หรือหยุดกลางทาง: ตั้งค่า → ความเร็วการส่งข้อมูล → **ช้า**
- กระดาษ 80 มม.: เปลี่ยนขนาดกระดาษในหน้าตั้งค่า

## หมายเหตุ
- เอกสารที่ออกเป็น **ใบเสร็จรับเงิน** ไม่ใช่ใบกำกับภาษี ถ้าร้านจด VAT และต้องออกใบกำกับภาษีอย่างย่อ ต้องขออนุมัติจากกรมสรรพากรก่อน
- การขายต้องต่ออินเทอร์เน็ต เพราะสต็อกถูกตัดที่ Google Sheets ส่วนตอนออฟไลน์ยังเปิดแอปดูสินค้าและใบเสร็จเก่าได้
- ถ้าแก้ `index.html` ให้เปลี่ยน `CACHE = 'pos-v4'` ใน `sw.js` เป็นเวอร์ชันใหม่ด้วย
